안전한 정리 도구

PowerShell 스크립트(.ps1)가 생성됩니다. 관리자 권한으로 실행하세요.

생성된 스크립트

실행 방법

  1. 위 스크립트를 다운로드하거나 복사합니다.
  2. PowerShell을 관리자 권한으로 실행합니다.
  3. 스크립트 실행 정책을 변경합니다: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  4. 스크립트를 실행합니다: .\disk-cleanup.ps1
  5. 각 단계별로 확인 메시지가 표시됩니다. Y/N으로 선택하세요.

디스크 조각 모음

HDD 사용자: Windows 검색에서 "조각 모음"을 검색하여 실행하세요. (SSD는 불필요)

🔄

Windows 업데이트

설정 → 업데이트 및 보안에서 최신 업데이트를 설치하세요.

악성코드 검사
